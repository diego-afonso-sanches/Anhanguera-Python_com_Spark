# Atividades da disciplina de Linguagens de Programação para Ciência de Dados com Python e Spark

Este repositório reúne as atividades desenvolvidas ao longo da disciplina, organizadas por temas e blocos de aprendizagem. Cada seção está conectada à sua respectiva pasta do projeto, facilitando a navegação entre teoria, exercícios e dados.

## Estrutura do projeto

### [Tema 1 — Fundamentos de Python para Ciência de Dados](Tema%201)

Pasta responsável pelos primeiros conceitos de programação em Python, configuração do ambiente e introdução às bibliotecas e manipulação de dados.

- [Tema_1_Bloco_1.ipynb](Tema%201/Tema_1_Bloco_1.ipynb)
- [Tema_1_Bloco_2.ipynb](Tema%201/Tema_1_Bloco_2.ipynb)
- [Tema_1_Bloco_3.ipynb](Tema%201/Tema_1_Bloco_3.ipynb)
- [Tema_1_Bloco_4.ipynb](Tema%201/Tema_1_Bloco_4.ipynb)
- Arquivos de dados: [vendas.csv](Tema%201/vendas.csv), [vendas_ecommerce.csv](Tema%201/vendas_ecommerce.csv), [vendas_processadas.csv](Tema%201/vendas_processadas.csv)

Objetivo: consolidar a base em Python, estrutura de dados, processamento inicial e preparação dos dados para etapas posteriores.

### [Tema 2 — Big Data e Apache Spark](Tema%202)

Pasta dedicada ao estudo de Big Data, conceitos de processamento distribuído e uso do Apache Spark em diferentes abordagens.

- [Tema_2_Bloco_3_demonstração.ipynb](Tema%202/Tema_2_Bloco_3_demonstração.ipynb)
- [Tema_2_Bloco_3_demonstração_RDD.ipynb](Tema%202/Tema_2_Bloco_3_demonstração_RDD.ipynb)
- [Tema_2_Bloco_3_demonstração_SQL.ipynb](Tema%202/Tema_2_Bloco_3_demonstração_SQL.ipynb)

Objetivo: explorar o funcionamento do Spark, RDDs e consultas SQL para análise de grandes volumes de dados.

### [Tema 3 — PySpark e análise de dados](Tema%203)

Pasta voltada para aplicações práticas de análise de dados com PySpark, incluindo manipulação de datasets, limpeza, agregação e exploração de informações em larga escala.

- [Tema_3_Bloco_1.ipynb](Tema%203/Tema_3_Bloco_1.ipynb)
- [Tema_3_Bloco_2.ipynb](Tema%203/Tema_3_Bloco_2.ipynb)
- [Tema_3_Bloco_3.ipynb](Tema%203/Tema_3_Bloco_3.ipynb)
- Dados: [clientes.json](Tema%203/clientes.json), [comportamento_cliente.json](Tema%203/comportamento_cliente.json), [dados_estoque.csv](Tema%203/dados_estoque.csv), [dados_vendas.csv](Tema%203/dados_vendas.csv), [pacientes_diabetes.csv](Tema%203/pacientes_diabetes.csv), [vendas.csv](Tema%203/vendas.csv)

Objetivo: aplicar os conceitos de Spark para transformar e analisar dados reais em cenários de ciência de dados.

### [Tema 4 — Aplicações avançadas e visualização de dados](Tema%204)

Pasta com exercícios focados em soluções mais avançadas e processamento final dos dados, com atenção à apresentação e interpretação dos resultados.

- [Tema_4_Bloco_3.py](Tema%204/Tema_4_Bloco_3.py)
- [Tema_4_Bloco_4.py](Tema%204/Tema_4_Bloco_4.py)

Objetivo: desenvolver aplicações mais robustas, automatizar processos e integrar análise com visualização de resultados.

## Visão geral dos temas

1. [Tema 1](Tema%201): base em Python e preparação dos dados.
2. [Tema 2](Tema%202): introdução ao Big Data e Spark.
3. [Tema 3](Tema%203): análise de dados com PySpark.
4. [Tema 4](Tema%204): aplicações avançadas e visualização.

Esse repositório forma uma sequência lógica de aprendizagem: a base em Python leva ao entendimento do Spark, que é aplicado em análises com PySpark e culmina em soluções mais avançadas de processamento e apresentação dos resultados.
